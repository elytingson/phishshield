# Data directory

## raw/

Place the untouched source dataset here:

`PhiUSIIL_Phishing_URL_Dataset.csv`

Do not manually edit the raw file.

## processed/

Generated datasets from the Chapter 3 preprocessing notebook belong here.

The repository `.gitignore` excludes raw and processed datasets by default to avoid accidentally publishing large or third-party data files.

Recommended metadata to record locally:

- source URL
- retrieval date
- checksum
- dataset version
- applicable license
- row / column dimensions

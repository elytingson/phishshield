# Security Policy

This project analyzes potentially malicious URL records.

## Safe handling

- Do not click or visit suspicious URLs during analysis.
- Do not download payloads, scripts, or attachments from suspicious sources.
- Prefer offline feature extraction from stored URL strings.
- Never commit confidential URLs, credentials, or private security incident data.
- Treat model outputs as risk estimates, not absolute safety guarantees.

For public demonstrations, use synthetic or clearly non-live example URLs.

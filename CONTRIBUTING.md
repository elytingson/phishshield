# Contributing

This repository is primarily an academic capstone project.

If extending the project:

1. Do not commit raw suspicious URLs or private organizational data.
2. Do not fetch live malicious webpages in automated tests.
3. Preserve domain-grouped evaluation when comparing models.
4. Keep preprocessing fitted on training data only.
5. Document new features and whether they are available pre-click.
6. Add or update tests for reusable helper functions.
